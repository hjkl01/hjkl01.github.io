### [excelize](https://github.com/qax-os/excelize) ![GitHub Repo stars](https://img.shields.io/github/stars/qax-os/excelize?style=social)

Excelize 是一个纯 Go 语言编写的开源库，专门用于读取和写入 Microsoft Excel 2007 及后续版本支持的多种文件格式（如 XLSX、XLSM、XLAM、XLTM、XLTX）。该库具备高兼容性，支持复杂表格组件操作，并提供流式 API 以高效处理海量数据。核心功能涵盖工作表创建与管理、单元格数据读写、图表自动生成以及图片插入与排版。项目要求 Go 1.25.0 或以上版本，采用 BSD-3-Clause 协议发布。
