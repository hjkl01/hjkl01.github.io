### [comprehensive-rust](https://github.com/google/comprehensive-rust) ![GitHub Repo stars](https://img.shields.io/github/stars/google/comprehensive-rust?style=social)

Comprehensive Rust 是由谷歌 Android 团队开发的多日 Rust 培训课程，旨在帮助具备 C++ 或 Java 背景的资深软件工程师全面掌握 Rust 语言。课程内容涵盖基础语法、泛型、错误处理，并深入探讨 Android、Chromium、裸机编程及并发等特定领域场景。该项目提供完整的课程源码、构建工具链及多语言支持，主要用于课堂教学，同时也支持本地化部署与贡献。
