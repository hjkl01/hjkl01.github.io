### [topcoat](https://github.com/tokio-rs/topcoat) ![GitHub Repo stars](https://img.shields.io/github/stars/tokio-rs/topcoat?style=social)

Topcoat 是一个面向 Rust 的全栈框架，专注于构建全栈应用。它采用服务器端渲染技术，通过 `view!` 宏和组件系统提供强大的 HTML 模板功能，支持异步组件直接查询数据库，减少传统前后端分离的样板代码。框架还包含基于模块的路由、内置 Tailwind CSS 支持、资产捆绑、客户端交互（无需 Wasm）以及可编辑的预置 UI 组件等特性，旨在简化开发流程并提升生产力。当前处于实验阶段，存在破坏性变更风险。
