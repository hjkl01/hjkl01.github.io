### [FluentCleaner](https://github.com/builtbybel/FluentCleaner) ![GitHub Repo stars](https://img.shields.io/github/stars/builtbybel/FluentCleaner?style=social)

FluentCleaner 是一款现代、透明且无广告的软件清理工具。它采用 WinUI 3 构建（另附带支持老旧系统的 .NET Framework 经典版），通过解析社区维护的 `winapp2.ini` 规则库来精确扫描和删除各类缓存、临时文件及残留数据。该工具旨在提供纯净的本地清理体验，不包含任何注册表清理器、安全删除功能或欺诈性营销，强调实际价值而非花哨噱头。
