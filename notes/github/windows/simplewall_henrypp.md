### [simplewall](https://github.com/henrypp/simplewall) ![GitHub Repo stars](https://img.shields.io/github/stars/henrypp/simplewall?style=social)

simplewall 是一款基于 Windows Filtering Platform (WFP) 的网络过滤管理工具，无需配合 Windows 防火墙使用。其主要功能包括：提供简洁无干扰的用户界面、支持自定义创建全局或特定应用程序的网络规则（白名单/黑名单）、内置阻止 Windows 遥测与间谍软件的屏蔽列表、记录被拦截的数据包通知、以及支持 WSL、Windows Store 和服务的网络权限控制。该软件为开源免费应用，兼容 Windows 7 至 11 系统。
