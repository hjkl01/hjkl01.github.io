### [HypoMux](https://github.com/Hypostasis-Cat/HypoMux) ![GitHub Repo stars](https://img.shields.io/github/stars/Hypostasis-Cat/HypoMux?style=social)

HypoMux v2.0 是一款专为 Windows 平台打造的多网卡带宽并发聚合下载加速工具。它支持通过系统代理或虚拟网卡模式，将多网络连接（如以太网、Wi-Fi、手机共享）的流量分配给多线程下载任务（如 Steam、IDM），从而实现带宽叠加与稳定加速；同时具备高级分流规则，允许用户按进程或域名设置直连或聚合通道，以平衡下载速度与低延迟应用体验。
