### [open-oscar-server](https://github.com/mk6i/open-oscar-server) ![GitHub Repo stars](https://img.shields.io/github/stars/mk6i/open-oscar-server?style=social)

Open OSCAR Server 是一个使用 Go 语言开发的开源即时通讯服务器，兼容经典的 AIM 和 ICQ 客户端。该项目独立且非商业，主要功能包括支持多种 AIM 和 ICQ 客户端版本，提供即时消息、离线消息、好友列表、群聊、文件共享、用户资料管理及隐私控制等功能，并附带用于服务器管理的 API。
