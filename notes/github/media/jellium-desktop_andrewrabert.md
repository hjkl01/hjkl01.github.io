### [jellium-desktop](https://github.com/andrewrabert/jellium-desktop) ![GitHub Repo stars](https://img.shields.io/github/stars/andrewrabert/jellium-desktop?style=social)

Jellium Desktop 是一款基于 CEF 和 mpv 开发的非官方 Jellyfin 桌面客户端，全面支持 Linux、macOS 和 Windows 平台。项目提供各架构的安装包下载，并内置 `just` 命令工具供开发者进行应用构建、运行、测试与代码检查。
