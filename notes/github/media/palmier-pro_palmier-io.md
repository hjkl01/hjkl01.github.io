### [palmier-pro](https://github.com/palmier-io/palmier-pro) ![GitHub Repo stars](https://img.shields.io/github/stars/palmier-io/palmier-pro?style=social)

Palmier Pro 是一款专为 Mac 设计的开源视频编辑器，旨在将 AI 深度整合至视频工作流中。其核心功能包括：

1. **原生开发**：基于 Swift 从零构建，对标 Premiere Pro 的体验。
2. **内置生成式 AI**：支持在时间轴内直接使用 Seedance、Kling 等顶尖模型生成视频和图像。
3. **AI 智能体集成**：通过 MCP 协议连接 Claude、Codex、Cursor 等外部工具，或应用内智能体协同编辑同一项目。
4. **免费与开源**：视频编辑器及 MCP 服务器完全免费且开源（生成式 AI 处理部分除外），支持 macOS Apple Silicon 平台。
