# Omarchy 项目功能总结

Omarchy 是由 DHH 开发的一款现代化、有个性的 Linux 发行版。

**核心功能：**
- 提供完整的桌面环境，支持顶部栏、主题定制和快捷键操作
- 集成统一剪贴板与历史记录管理
- 内置提醒和通知系统
- 支持文本提取与语音输入功能
- 提供截图和屏幕录制工具
- 包含 AI 助手和开发工具套件
- 支持终端（Neovim）、Shell 工具、TUI/GUI 应用、浏览器等多种应用
- 兼容商业应用服务和 Web 应用
- 提供游戏平台支持
- 内置 PDF 填写功能和 Windows 虚拟机支持

**系统配置与管理：**
- 灵活的更新机制和配置文件管理
- 支持 Shell 插件和显示器/键盘/鼠标/触控板配置
- 网络管理和系统休眠设置
- 硬件认证和字体/背景自定义
- 提供系统快照和安全功能
- 支持 Mac 平台和双启动/无干预安装方式
