### [open-code-review](https://github.com/alibaba/open-code-review) ![GitHub Repo stars](https://img.shields.io/github/stars/alibaba/open-code-review?style=social)

OpenCodeReview 是一款阿里巴巴集团开源的 AI 驱动的代码审查 CLI 工具。它基于 Git Diff，通过支持工具使用的智能体将代码发送给大语言模型，生成结构化的行级精准评论。其核心采用确定性工程与智能体的混合架构，具备精确文件选择、智能捆绑、细粒度规则匹配以及独立定位和反射模块等特点，旨在提供比通用型代理更高精度且更高效的代码审查服务。
