### [kimi-code](https://github.com/MoonshotAI/kimi-code) ![GitHub Repo stars](https://img.shields.io/github/stars/MoonshotAI/kimi-code?style=social)

Kimi Code CLI 是一款运行在终端中的 AI 编程代理，具备读取和编辑代码、执行 Shell 命令、搜索文件、抓取网页及根据反馈自主决策的能力。其核心功能包括：单二进制文件分发（无需 Node.js）、毫秒级快速启动、专为长会话优化的终端界面、视频输入理解、基于对话的 MCP 配置、丰富的插件生态、支持并行工作的子代理机制、生命周期钩子以及通过 Agent Client Protocol (ACP) 实现与 Zed、JetBrains 等 IDE 的深度集成。
