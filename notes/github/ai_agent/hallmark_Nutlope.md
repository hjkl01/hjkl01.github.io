### [hallmark](https://github.com/Nutlope/hallmark) ![GitHub Repo stars](https://img.shields.io/github/stars/Nutlope/hallmark?style=social)

Hallmark 是一款专为 Claude Code、Cursor 和 Codex 设计的 UI 设计技能插件，旨在生成高质量、非模板化且避免“AI 生成感”的前端页面。它通过自动匹配宏观结构与 20 种预设主题（或启用自定义模式），结合 57 项质量过滤与自我审查机制，确保不同需求产出截然不同的视觉风格。项目提供四大核心指令：默认构建新 UI、审计现有代码质量、重构保留文案与品牌但更换底层布局、以及从截图或链接中提取设计 DNA 并导出配置。最终输出自包含的 HTML 与 CSS 文件，采用 MIT 协议开源。
