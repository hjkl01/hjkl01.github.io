### [DocsGPT](https://github.com/arc53/DocsGPT) ![GitHub Repo stars](https://img.shields.io/github/stars/arc53/DocsGPT?style=social)

DocsGPT 是一个开源 AI 平台，专注于构建企业级智能代理、助手和内部搜索系统。核心功能包括：

1. **多格式文档处理**：支持 PDF、Office 文档、网页、音频等多种格式的文件分析和检索。
2. **语音工作流**：录音转文字、会议纪要语音备忘入库，支持音频知识搜索。
3. **多模型灵活部署**：兼容 OpenAI、Google、Anthropic 等主流 API，也支持本地模型（Ollama、llama_cpp）运行。
4. **隐私优先**：支持私有化部署、Kubernetes 容器化运行，保障数据安全。
5. **代理工具链**：提供 Agent Builder、深度研究工具、API 连接、可操作工具集成，支持 HTML/React 聊天组件、Discord/Telegram 机器人等预构建方案。
6. **企业级能力**：OIDC/SSO 登录、RBAC 角色权限、SharePoint/Confluence 连接器、团队共享与权限管理。
