### [craft-agents-oss](https://github.com/craft-ai-agents/craft-agents-oss) ![GitHub Repo stars](https://img.shields.io/github/stars/craft-ai-agents/craft-agents-oss?style=social)

Craft Agents 是一款基于 Agent Native 理念构建的开源桌面应用及服务器端工具，旨在提供高效、直观的 AI 智能体工作流。其核心功能包括：

1. **多模型与多提供商支持**：无缝集成 Anthropic (Claude)、Google AI Studio、ChatGPT Plus、GitHub Copilot 及 OpenAI 等多种大语言模型后端。
2. **自动化连接与配置**：通过自然语言指令即可自动发现、配置并连接 MCP 服务器、REST API（如 Linear、Slack、Gmail）及本地文件，无需手动编写配置文件。
3. **强大的会话与工作区管理**：支持多会话并行、状态工作流（待办/进行中/完成）、权限分级控制（只读/询问/自动）以及背景任务追踪。
4. **灵活部署模式**：提供 Electron 桌面客户端、无头远程服务器（支持 Docker 部署）以及命令行界面（CLI），满足从日常交互到 CI/CD 集成等不同场景需求。
5. **高级特性**：内置事件驱动自动化引擎、加密凭证存储、大响应智能摘要、深链接跳转及丰富的自定义技能（Skills）系统。
