### [paperclip](https://github.com/paperclipai/paperclip) ![GitHub Repo stars](https://img.shields.io/github/stars/paperclipai/paperclip?style=social)

Paperclip 是一个开源的 AI 代理编排平台，专为团队协作设计。其核心理念是：将多个 AI 代理（如 Claude Code、Codex、Cursor 等）组织成“公司”，通过统一仪表板进行目标对齐、任务分配、成本监控和治理管理。

**主要功能：**
- **任务管理**：声明业务目标，代理自主执行，人工审核结果。
- **组织架构图**：创建混合人类与代理的层级结构，明确角色、权限和汇报关系。
- **代理培训与评估**：设计技能、运行测试、建立质量反馈闭环。
- **基础设施层**：跨模型/代理运行时、沙盒环境、密钥管理、SSO 和成本控制在内。
- **目标对齐**：所有任务追溯至公司使命，确保代理知晓“为何而做”。
- **心跳机制**：代理定时唤醒，持续检查并推进工作，支持委托与恢复。
- **成本控制**：按代理设置预算，超限自动暂停，防止资源浪费。
- **多公司支持**：单一部署可隔离运营多个独立公司。
- **治理与审批**：雇佣、策略覆盖、暂停或终止代理均需人工审批。
- **工单系统**：完整记录对话、决策和工具调用，提供可审计日志。
- **移动友好**：随时随地通过手机监控和管理代理团队。

**解决的痛点：**
- 多个代理并行工作时任务分散、上下文丢失。
- 缺乏统一的协调、沟通与成本监控机制。
- 手动启动常规任务容易遗漏。
- 代理重启后无法恢复工作状态。

**技术架构：** Node.js 后端 + React 前端，支持多种代理适配器（包括自定义 HTTP/Webhook 机器人）。开源许可 MIT，可自托管。
