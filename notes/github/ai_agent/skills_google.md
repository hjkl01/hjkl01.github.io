# Agent Skills 项目总结

本项目是 Google 官方维护的 **Agent Skills 仓库**，提供针对 Google 产品及技术的智能体技能，涵盖 Google Cloud、AI/ML、基础设施、数据库、开发者工具等多个领域。

## 核心功能

- **安装方式**：通过 `npx skills add google/skills` 命令安装技能
- **技能分类**：
  - Google Cloud 入门与多产品解决方案
  - AI/ML（Agent Platform、Gemini API、BigQuery AI 等）
  - 基础设施（GKE 集群管理、网络、存储、TPU 等）
  - 数据库与分析（BigQuery、AlloyDB、Cloud SQL、Spanner 等）
  - 开发者工具（gcloud CLI、开发者设备平台等）
  - 管理工具（Cloud Monitoring、Cloud Logging、成本优化、SLO 告警等）
  - 良好架构框架（成本、运维、性能、可靠性、安全、可持续性六大支柱）
  - 安全与身份（GKE 平台安全、SecOps 检测覆盖等）
  - Web 与应用托管（Cloud Run、Firebase）
  - 广告（Google Ads API、移动广告 SDK、IMA SDK）
  - 数据分析（Google Analytics Admin/Data API）

- **支持的 Agent 工具**：Claude Code、Codex、Antigravity CLI
- **开源许可**：Apache 2.0，欢迎贡献技能和反馈问题
