# AutoGPT 项目功能总结

AutoGPT 是一个开源的 AI 代理平台，允许用户构建、部署和运行 AI 代理来执行完整的工作流程。

**核心功能：**

1. **四种使用方式：**
   - AutoPilot：用自然语言描述任务，自动生成可工作的代理
   - Agents：集中查看所有代理、运行记录和成本统计
   - Marketplace：获取社区现成的代理模板并自定义
   - Build：通过可视化拖拽精确控制每个工作流步骤

2. **部署选择：**
   - 托管平台：开箱即用，包含基础设施和模型接入（付费）
   - 自托管：免费开源，用户自行部署（需自备API密钥和基础设施）

3. **集成能力：**
   - 支持45+主流平台（Gmail、Google日历、GitHub、Slack、Notion、Salesforce等）
   - 接入数百个AI模型

4. **适用场景：**
   - 行政运营（日常简报）
   - 销售（客户研究）
   - 营销（多渠道内容生成）
   - 工程（事件分类）
   - 客服（回复草稿）
   - 研究（信息监控与报告）
