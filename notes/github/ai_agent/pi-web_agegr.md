### [pi-web](https://github.com/agegr/pi-web) ![GitHub Repo stars](https://img.shields.io/github/stars/agegr/pi-web?style=social)

Pi Web 是 pi coding agent 的本地 Web 用户界面，用于读取本地 pi 会话文件并提供浏览器工作区。核心功能包括：会话浏览、实时聊天、模型配置、技能管理以及项目文件预览（支持源码、文档、图片、音频和 PDF）。它还支持从早期消息恢复或分叉会话以安全尝试不同方向，通过侧边栏切换 Git worktrees，并在顶部状态栏清晰展示上下文用量、成本及系统提示词等会话状态信息。
