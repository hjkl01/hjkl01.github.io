### [langflow](https://github.com/langflow-ai/langflow) ![GitHub Repo stars](https://img.shields.io/github/stars/langflow-ai/langflow?style=social)

Langflow 是一个用于构建和部署 AI 驱动的智能体与工作流的强大平台。其核心功能包括：提供可视化构建界面以快速迭代，支持通过 Python 自定义组件，具备交互式游乐场进行实时测试，实现多智能体编排与对话管理，并可将工作流部署为 API、JSON 格式或 MCP 服务器以便集成到各类应用中。此外，该平台集成了 LangSmith、LangFuse 等可观测性工具，具备企业级安全与扩展能力，支持主流大语言模型及向量数据库。
