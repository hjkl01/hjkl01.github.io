### [skills](https://github.com/NVIDIA/skills) ![GitHub Repo stars](https://img.shields.io/github/stars/NVIDIA/skills?style=social)

NVIDIA Agent Skills 是 NVIDIA 官方验证的 AI 代理技能集，旨在指导 AI 代理高效使用 CUDA-X 库、AI Blueprints 及平台工具。该项目提供统一的技能目录，涵盖 AI 开发、优化、数据处理、物理 AI、医疗影像及边缘计算等多个领域。通过标准化的 `skills` CLI 工具，用户可便捷地将这些经过安全签名和评估的技能安装至各类 AI 编程代理（如 Claude Code、Codex 等），从而增强代理在特定 NVIDIA 技术栈上的任务执行能力与安全性。
