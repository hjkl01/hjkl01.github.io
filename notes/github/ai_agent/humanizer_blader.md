### [humanizer](https://github.com/blader/humanizer) ![GitHub Repo stars](https://img.shields.io/github/stars/blader/humanizer?style=social)

Humanizer 是一款可移植的 Agent Skill，用于消除文本中人工智能生成的痕迹，使其听起来更自然、更像人类写作。它基于 Wikipedia 的“AI写作迹象”指南，能识别并修正 33 种 AI 写作模式（包括内容、语言、风格及表达习惯），同时遵循“不虚构事实”原则——不会添加原文中没有的名称、日期或引用。支持通过指令粘贴文本、处理文件或结合用户个人写作样本进行语气校准，适配多种 Agent 环境（如 Skills CLI、Claude Code 插件或直接复制 SKILL.md）。
