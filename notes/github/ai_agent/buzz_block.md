### [buzz](https://github.com/block/buzz) ![GitHub Repo stars](https://img.shields.io/github/stars/block/buzz?style=social)

Buzz 是一个由 Block, Inc. 开发的自托管工作区，基于 Nostr 协议构建。其核心功能是让 AI 代理与人类在同一个空间内协作，将消息、代码审查、工作流和 Git 事件统一为可审计的签名事件日志。主要特性包括：

1. **人机协同**：AI 代理作为拥有独立身份和权限的成员加入频道，具备与人类相同的操作能力（如打开仓库、提交补丁、运行工作流等）。
2. **统一工作流**：以“频道”为核心，将功能分支、补丁、CI 结果、审核意见和合并决策整合在同一记录中，实现全链路可追溯。
3. **智能记忆与检索**：代理可基于历史事件日志回答项目问题，提供带证据链的回答；支持对对话、补丁和工作流的统一搜索。
4. **自动化支持**：通过 YAML 定义的工作流自动触发任务，代理可参与发布笔记起草、Bug 分类及 incident 排查等场景。
5. **多平台客户端**：提供桌面端（Tauri + React）、CLI 工具（buzz-cli）及移动端开发计划，支持本地部署和多租户架构。
