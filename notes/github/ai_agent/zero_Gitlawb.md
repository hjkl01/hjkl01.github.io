### [zero](https://github.com/Gitlawb/zero) ![GitHub Repo stars](https://img.shields.io/github/stars/Gitlawb/zero?style=social)

Zero 是一个开源的终端 AI 编码代理工具，旨在让用户完全掌控自己的代码辅助环境。

**核心功能：**
- 支持接入 25+ 主流 AI 模型提供商（如 OpenAI、Anthropic、Gemini、DeepSeek、Ollama 等），用户可自由选择模型
- 提供交互式 TUI 界面和无头命令行模式，支持脚本化和 CI/CD 集成
- 所有会话数据本地持久化存储，不上传任何遥测数据
- 内置完善的权限和沙箱机制，文件写入、Shell 命令、网络访问等操作均需用户授权

**主要特点：**
- 支持图像输入、多轮对话、会话恢复和分支
- 可通过 MCP 服务器、技能、插件和子代理进行扩展
- 支持 Git 工作区隔离、仓库分析和上下文管理
- 提供主题定制和终端友好型交互体验

**适用场景：**
本地开发辅助、批量代码任务、自动化测试修复、代码重构等编程工作，既适合日常交互式使用，也可集成到自动化流程中。
