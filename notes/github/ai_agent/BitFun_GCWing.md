# BitFun 项目功能总结

**BitFun** 是一款桌面 AI 代理应用，能够将每个任务转化为可打开的应用程序界面。

## 核心功能

1. **智能 Mini Apps**：为每个任务自动生成专属界面（图表、看板、表单、面板等），对话与界面实时状态绑定，用户可直接查看屏幕内容进行交互。

2. **自托管多设备控制**：支持跨设备登录、会话同步和远程设备控制，通过用户自部署的中继服务器运行，零知识架构，不依赖厂商云服务。

3. **编码能力**：在真实 Git 仓库中完成规划、编辑、测试、提交全流程，支持智能体模式、调试、深度审查和长周期任务。

4. **办公工作**：支持研究、写作、演示文稿、会议纪要、报告生成等文档类任务。

5. **桌面执行**：可操作浏览器、终端、桌面应用、文件系统和远程工作区，直接接入真实工作环境。

6. **四级定制化**：
   - L1：自定义 Agent（角色、流程、约束）
   - L2：MCP / Skills / Hooks（连接外部工具，兼容 Codex Hooks）
   - L3：Mini App（生成专属界面）
   - L4：源代码级定制（修改工具、适配器、UI、运行时）

7. **高性能**：
   - KV Cache 命中率 98.67%，大幅降低代理运行成本
   - flashgrep 搜索工具在 Chromium 级代码库中提升 36 倍速度，搜索时间减少 94.6%

8. **跨平台**：支持 Windows、macOS、Linux，用户可自由选择运行的模型。

## 典型应用场景

- **代码开发**：从真实仓库到可合并结果的完整软件开发流程
- **办公文档**：从原始资料到报告、演示文稿等交付物

## 技术特点

- 基于 Rust 运行时和 Tauri 框架
- 支持社区 Mini App 市场扩展
- 开源（MIT 协议）
