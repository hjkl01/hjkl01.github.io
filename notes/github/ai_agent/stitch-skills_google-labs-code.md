### [stitch-skills](https://github.com/google-labs-code/stitch-skills) ![GitHub Repo stars](https://img.shields.io/github/stars/google-labs-code/stitch-skills?style=social)

该项目为 Google Stitch 提供了一套遵循 Agent Skills 开放标准的智能体插件，兼容 Codex、Claude Code、Cursor 等编程代理（需预先配置 Stitch MCP 服务器）。核心功能分为三大模块：
1. **设计工作流**：支持前端代码转设计、图文生成/编辑界面、管理设计系统、提取设计文档与静态页面，以及本地资源上传。
2. **代码生成与构建**：可将 Stitch 设计自动转换为 React 组件、React Native 应用、Remotion 演示视频或 shadcn-ui/Vite 仪表盘，并处理框架集成与资产编译。
3. **辅助工具**：提供提示词优化增强、自动生成标准化 DESIGN.md 文档、多页面网站一键生成及高端 UI 风格校验。
项目旨在通过标准化技能包，全面提升 AI 辅助 UI 设计、原型开发至代码落地的全流程效率。
