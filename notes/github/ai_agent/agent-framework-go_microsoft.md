### [agent-framework-go](https://github.com/microsoft/agent-framework-go) ![GitHub Repo stars](https://img.shields.io/github/stars/microsoft/agent-framework-go?style=social)

Microsoft Agent Framework (Go版) 是一个用于构建生产级 AI 智能体和多智能体工作流的开源框架。它支持图基模式（如顺序、并发、协作和自定义路由），提供检查点、可观测性、治理及人工干预控制功能，并具备提供商灵活性。核心特性包括多智能体提供商支持、中间件、工作流编排、Microsoft Foundry 集成、OpenTelemetry 可观测性以及智能体技能构建。
