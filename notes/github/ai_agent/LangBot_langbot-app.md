### [LangBot](https://github.com/langbot-app/LangBot) ![GitHub Repo stars](https://img.shields.io/github/stars/langbot-app/LangBot?style=social)

LangBot 是一个开源的生产级平台，用于构建面向即时通讯（IM）的 AI 智能体机器人。其核心功能包括：

1. **多平台支持**：统一代码库支持接入 Discord、Telegram、Slack、LINE、QQ、微信（个人号及企业微信）、飞书、钉钉、KOOK 等主流及小众 IM 平台。
2. **AI 能力集成**：支持多轮对话、工具调用、多模态交互及流式输出；内置 RAG（知识库），并深度集成 Dify、Coze、n8n、Langflow 等 AI 工作流平台。
3. **广泛的大模型兼容**：支持 OpenAI、Anthropic、DeepSeek、Google Gemini 以及各类本地部署模型和聚合网关。
4. **生产级特性**：提供访问控制、速率限制、敏感词过滤、全面监控及异常处理机制。
5. **插件生态与扩展**：拥有事件驱动的插件生态系统，支持 MCP 协议，便于功能扩展。
6. **可视化管控**：提供基于 Web 的管理面板，无需编写 YAML 即可直观地配置、管理和监控机器人。
7. **Agent 友好设计**：原生支持 MCP 协议和内置 Skills，方便 Claude Code、Cursor 等 AI 编码代理直接操作、扩展和部署机器人。
