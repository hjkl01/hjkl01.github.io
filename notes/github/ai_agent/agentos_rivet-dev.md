### [agentos](https://github.com/rivet-dev/agentos) ![GitHub Repo stars](https://img.shields.io/github/stars/rivet-dev/agentos?style=social)

agentOS 是一个面向 AI 代理的便携式开源操作系统内核，以 npm 包形式运行于进程内部。其核心优势包括近零冷启动时间（约 6ms）、极低的内存占用和显著低于传统沙箱的成本。它提供细粒度的安全权限控制（默认拒绝）、内置对 Pi、Claude Code 等代理的支持，并具备会话持久化、多代理协作、工作流编排及与外部存储和沙箱扩展集成的能力。
