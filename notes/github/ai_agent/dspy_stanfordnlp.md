# DSPy 功能总结

DSPy（Declarative Self-improving Python）是一个用于**编程而非提示**大语言模型的框架。

**核心功能：**
- 用可组合的 Python 代码替代脆弱的提示词（prompt）
- 快速迭代构建模块化 AI 系统
- 提供算法自动优化提示词和模型权重
- 支持分类器、RAG 管道、Agent 循环等多种 AI 应用场景

**核心理念：**
通过声明式编程方式，教会语言模型交付高质量输出，而非手工编写提示词。
