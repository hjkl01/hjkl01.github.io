### [agent-orchestrator](https://github.com/AgentWrapper/agent-orchestrator) ![GitHub Repo stars](https://img.shields.io/github/stars/AgentWrapper/agent-orchestrator?style=social)

Agent Orchestrator 是一个用于并行 AI 编程代理的编排层（Agentic IDE）。它主要在隔离的工作空间中监督多个 AI 编码代理，提供完全的控制权，并具备自动反馈循环机制，能够处理 CI 失败、代码审查意见和合并冲突。该平台支持 23 种以上的代理适配器，采用平台原生运行时，并通过 SQLite 持久化存储事实数据，最终封装为带有 React UI 和本地终端流式传输的桌面应用程序。
