### [openpencil](https://github.com/ZSeven-W/openpencil) ![GitHub Repo stars](https://img.shields.io/github/stars/ZSeven-W/openpencil?style=social)

OpenPencil 是全球首款开源的 AI 原生矢量设计工具。其核心功能包括：通过自然语言提示词实时生成 UI 设计，支持并发 AI 智能体团队并行处理复杂页面；具备多模型智能适配能力，内置 MCP Server 可无缝集成至各类终端 AI 工具；采用“设计即代码”理念，`.op` 文件基于 JSON 格式，支持导出为 React、Vue、Flutter 等多种前端及移动端代码；提供强大的设计系统管理、Figma 导入、Git 版本控制及全平台（Web/桌面）运行支持。
