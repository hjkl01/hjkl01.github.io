### [openwork](https://github.com/different-ai/openwork) ![GitHub Repo stars](https://img.shields.io/github/stars/different-ai/openwork?style=social)

OpenWork 是一款免费开源的桌面应用，用于跨平台（macOS、Windows、Linux）分享 AI 工作流程。核心功能包括：

1. **跨工具共享工作流**：将 OpenWork MCP 接入 Codex、Claude Code、Cursor 等 AI 代理，实现技能、插件和连接服务的跨工具、跨设备重用。

2. **代理集成**：支持一键安装和配置，通过 MCP 暴露 `search_capabilities` 和 `execute_capability` 两个工具，可访问 Google Workspace 和 Microsoft 365 等服务。

3. **组织管理**：OpenWork Den 提供控制平面，支持大规模推理分配、团队成员管理、桌面策略设置、技能发布与权限控制。
