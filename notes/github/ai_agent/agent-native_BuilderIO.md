### [agent-native](https://github.com/BuilderIO/agent-native) ![GitHub Repo stars](https://img.shields.io/github/stars/BuilderIO/agent-native?style=social)

Agent-Native 是一个开源框架，用于构建深度集成在真实应用中的智能体（Agent），而非仅作为聊天辅助。其核心功能包括：

1.  **统一行动原语**：定义一次操作，即可在 UI、Agent、API、MCP、A2A 和 CLI 中复用。
2.  **全栈 Agent 运行时**：提供聊天、工具、技能、记忆、作业调度、可观测性及交接功能。
3.  **前后端解耦与同步**：支持任意 Drizzle 兼容的 SQL 数据库和 Nitro 兼容的主机，实现 UI 与 Agent 状态实时同步及多用户协作。
4.  **丰富的模板库**：提供多种现成的开源 SaaS 应用模板（如 Clips, Plans, Design, Content, Slides, Analytics），涵盖屏幕录制、视觉规划、原型设计、文档编辑、演示文稿生成及数据分析等场景。
5.  **技能扩展与快速启动**：支持通过命令将视觉规划和 PR 回顾等功能添加到现有开发工具（如 Claude Code, Cursor 等），并提供一键创建项目的快速启动方式，支持从完整模板到无头模式的多种初始化选项。
