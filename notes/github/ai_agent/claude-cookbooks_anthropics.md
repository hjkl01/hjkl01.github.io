### [claude-cookbooks](https://github.com/anthropics/claude-cookbooks) ![GitHub Repo stars](https://img.shields.io/github/stars/anthropics/claude-cookbooks?style=social)

本项目为开发者提供了一系列基于 Claude API 的代码示例与实战指南，旨在帮助快速集成 AI 并构建应用程序。核心内容涵盖文本处理（分类、摘要）、检索增强生成（RAG）、外部工具与第三方数据源集成、多模态能力（视觉识别与图像生成），以及高级开发技巧（提示词缓存、JSON 模式、内容审核、子代理架构等）。示例主要使用 Python 编写，但核心逻辑兼容多种编程语言，并支持社区持续贡献与优化。
