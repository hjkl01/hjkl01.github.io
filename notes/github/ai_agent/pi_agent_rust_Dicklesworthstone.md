### [pi_agent_rust](https://github.com/Dicklesworthstone/pi_agent_rust) ![GitHub Repo stars](https://img.shields.io/github/stars/Dicklesworthstone/pi_agent_rust?style=social)

pi_agent_rust 是一个用 Rust 编写的高性能 AI 编码助手 CLI 工具。其主要功能包括：支持流式响应、提供多种内置工具（如读写文件、执行命令等）、管理多分支对话会话，并具备扩展能力以集成自定义技能或脚本。项目注重启动速度与内存效率，同时采用沙箱化设计保障运行安全。
