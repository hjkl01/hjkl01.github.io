### [claurst](https://github.com/Kuberwastaken/claurst) ![GitHub Repo stars](https://img.shields.io/github/stars/Kuberwastaken/claurst?style=social)

Claurst 是一款基于 Rust 开发的开源、多提供商终端编程代理（TUI Pair Programmer）。它旨在为开发者提供快速、高效且无遥测追踪的编码辅助体验。主要功能包括：

1. **多模型支持**：支持接入多个 AI 提供商，灵活选择后端服务。
2. **丰富的交互特性**：具备插件系统、聊天分支、记忆整合以及内置助手 Rustle。
3. **实验性功能**：支持通过 GitHub Gist 分享会话、免费模式使用、长期目标驱动的任务执行（/goal）以及复杂的“超代码”工作流（ultracode），后者能自动分解任务并调度子代理协同工作。
4. **编辑器集成**：原生支持 Agent Client Protocol (ACP)，可无缝集成至 Zed、Neovim 等编辑器中作为子进程运行。
5. **跨平台与易用性**：提供一键安装脚本、npm/bun 全局包安装及源码编译支持，兼容 Linux、macOS 和 Windows 系统。
