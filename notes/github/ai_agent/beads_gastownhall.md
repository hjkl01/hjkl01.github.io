### [beads](https://github.com/gastownhall/beads) ![GitHub Repo stars](https://img.shields.io/github/stars/gastownhall/beads?style=social)

Beads 是一个基于 Dolt 的分布式图结构问题追踪系统，专为 AI 编程代理设计。它通过提供持久化的结构化记忆和依赖感知的图数据库，替代传统的 Markdown 计划文件，帮助代理在多分支、多代理协作及长周期任务中保持上下文连贯性，防止信息丢失。核心功能包括版本控制的 SQL 数据库支持、零冲突的哈希 ID、语义化记忆压缩、消息线程以及复杂的任务关联图谱。
