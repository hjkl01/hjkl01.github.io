**Android Skills 项目功能总结：**

Android Skills 是一个专为 AI 优化的模块化指令与资源仓库，帮助 AI agents 更好地理解和执行 Android 开发最佳实践。项目提供 SKILL.md 格式的标准化技能文件，聚焦于 LLMs 表现不佳的 Android 开发场景，可通过 Android CLI 安装并自动激活使用。
