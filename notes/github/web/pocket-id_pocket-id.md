### [pocket-id](https://github.com/pocket-id/pocket-id) ![GitHub Repo stars](https://img.shields.io/github/stars/pocket-id/pocket-id?style=social)

Pocket ID 是一款经过 OpenID Connect 认证的轻量级 OAuth 2.0 身份认证服务。它专注于无密码的 Passkey（通行证）登录，支持物理安全密钥（如 YubiKey），旨在为需要自托管认证服务的用户提供比 Keycloak 等方案更简单易用的选择，并支持通过 Docker 快速部署。
