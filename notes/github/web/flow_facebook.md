### [flow](https://github.com/facebook/flow) ![GitHub Repo stars](https://img.shields.io/github/stars/facebook/flow?style=social)

Flow 是 Facebook 开发的一款用于 JavaScript 的静态类型检查器。它支持 macOS、Linux 和 Windows 平台，可通过 npm 安装使用。其核心组件 Flow Parser 也可作为独立的 JavaScript 模块发布，供需要解析带类型标注的 Flow 代码的工具使用。项目源码主要使用 Rust 编写，支持从源代码构建。
