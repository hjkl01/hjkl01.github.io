### [Instatic](https://github.com/CoreBunch/Instatic) ![GitHub Repo stars](https://img.shields.io/github/stars/CoreBunch/Instatic?style=social)

Instatic 是一个自托管的 CMS，将所有功能（视觉编辑器、内容引擎、发布器等）集成在一个 Bun 服务器中。它使用 SQLite 或 Postgres 作为数据库，生成语义化的 HTML 和精简的 CSS，无需前端框架运行即可直接展示。主要特性包括：可视化画布与 Core Framework 设计系统、模块化组件构建、统一的内容模型管理、内置表单及分析仪表盘、基于 QuickJS-WASM 的沙箱化插件扩展以及 AI 页面生成工具。
