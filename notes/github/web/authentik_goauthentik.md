**authentik 项目功能总结**

authentik 是一款开源的身份提供商（IdP），专为现代单点登录（SSO）设计。它支持 SAML、OAuth2/OIDC、LDAP、RADIUS 等多种协议，适用于自托管环境，从小型测试到大规模生产集群均可部署。项目提供企业版，可替代 Okta、Auth0、Entra ID、Ping Identity 等现有 IdP 解决方案。支持 Docker Compose、Kubernetes（Helm Chart）、AWS CloudFormation 和 DigitalOcean 等多种部署方式。
