# chele.bi 功能总结

这是 Ege Chelebi 的个人博客与作品集网站，采用暗色编辑风格设计。

**核心功能：**
- MDX 博客系统，支持左侧目录导航、标注提示和文章专属装饰
- 根据文章标题自动生成确定性轮廓风格的封面图，无需手动上传
- 液体玻璃圆形控件与磨砂玻璃标签的 UI 设计
- 统一的轮廓标识系统，驱动网站 Logo 和浏览器图标

**技术栈：** Next.js 14 (App Router)、React 18、TypeScript、MDX、Tailwind CSS、Biome（代码检查与格式化）

**部署：** Vercel，本地开发支持 Bun 包管理器，无需环境变量配置。
