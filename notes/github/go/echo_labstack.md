### [echo](https://github.com/labstack/echo) ![GitHub Repo stars](https://img.shields.io/github/stars/labstack/echo?style=social)

Echo 是一个高性能、可扩展、极简主义的 Go Web 框架。基于 Go 标准库 `net/http` 构建，提供快速的路由树、请求数据绑定（支持 JSON、XML 和表单）、可扩展的中间件系统、集中式错误处理、模板渲染等功能。支持 API 分组、HTTP/2、自动 TLS（Let's Encrypt），高度可定制，适用于构建健壮可扩展的 RESTful API。当前主流版本为 v5，采用 MIT 开源协议。
