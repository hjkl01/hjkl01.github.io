### [unstract](https://github.com/Zipstack/unstract) ![GitHub Repo stars](https://img.shields.io/github/stars/Zipstack/unstract?style=social)

Unstract 是一款基于大语言模型（LLM）的文档数据提取平台，可将非结构化文档（PDF、图片、扫描件等）转换为结构化 JSON 数据。支持通过自然语言提示定义提取模式，提供 Prompt Studio 交互界面、REST API 部署和 ETL 管道功能，可集成多种 LLM 提供商（OpenAI、Anthropic、Ollama 等）和向量数据库，支持与 AI 代理（MCP Server）及工作流自动化（n8n）集成，适用于金融、保险、医疗、合规等领域的文档自动化处理。
