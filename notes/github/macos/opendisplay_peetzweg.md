### [opendisplay](https://github.com/peetzweg/opendisplay) ![GitHub Repo stars](https://img.shields.io/github/stars/peetzweg/opendisplay?style=social)

OpenDisplay 是一个免费、开源的工具，允许用户将闲置的 Apple 设备（iPhone/iPad）用作 Mac 的第二扩展显示器。它通过 USB 或 WiFi 连接提供低延迟的 Retina 级显示和触控输入，无需账号、硬件狗或付费订阅，旨在替代 Sidecar、Duet Display 等方案。
