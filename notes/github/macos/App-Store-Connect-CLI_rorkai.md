### [App-Store-Connect-CLI](https://github.com/rorkai/App-Store-Connect-CLI) ![GitHub Repo stars](https://img.shields.io/github/stars/rorkai/App-Store-Connect-CLI?style=social)

App Store Connect CLI 是一个快速、轻量且可脚本化的命令行工具，用于通过 Apple App Store Connect API 自动化 iOS、macOS、tvOS 和 visionOS 的发布工作流。它支持构建管理、TestFlight 分发、元数据同步、签名及审核状态查询等操作，适用于终端、IDE 或 CI/CD 环境。
