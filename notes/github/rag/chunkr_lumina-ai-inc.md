### [chunkr](https://github.com/lumina-ai-inc/chunkr) ![GitHub Repo stars](https://img.shields.io/github/stars/lumina-ai-inc/chunkr?style=social)

Chunkr 是一款开源文档智能 API 服务，专为生产环境设计，提供文档布局分析、光学字符识别（OCR）及语义分块功能。它支持将 PDF、PPT、Word 文档及图片转换为适用于 RAG（检索增强生成）和 LLM 的结构化数据（如 HTML 和 Markdown），并具备视觉语言模型处理能力。该项目可通过 Docker Compose 快速部署，支持 GPU/CPU 环境，允许配置多种大语言模型提供商，采用 AGPL-3.0 或商业许可证。
