### [ai-agent-book](https://github.com/bojieli/ai-agent-book) ![GitHub Repo stars](https://img.shields.io/github/stars/bojieli/ai-agent-book?style=social)

这是一本关于 AI Agent 设计原理与工程实践的开源书籍，通过 10 章内容深入讲解了从 Agent 基础知识到多 Agent 协作的全景知识体系。围绕核心公式 **Agent = LLM + 上下文 + 工具** 展开，涵盖上下文工程、用户记忆、工具使用、代码生成、模型评估、后训练、持续进化及多模态交互等关键领域，并配有 92 个配套实验项目以支持实践。
