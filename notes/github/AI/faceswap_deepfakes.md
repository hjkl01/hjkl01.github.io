### [faceswap](https://github.com/deepfakes/faceswap) ![GitHub Repo stars](https://img.shields.io/github/stars/deepfakes/faceswap?style=social)

FaceSwap 是一个利用深度学习技术识别和交换图片或视频中面部的开源工具。项目主要功能包括：

1. **提取（Extract）**：从图片中提取面部图像
2. **训练（Train）**：使用提取的面部图像训练面部交换模型
3. **转换（Convert）**：使用训练好的模型进行面部交换
4. **图形界面（GUI）**：提供可视化的操作界面

项目由 Python 编写，支持 Windows、Linux 和 MacOS 系统，需要配备支持 CUDA 的现代 GPU 以获得最佳性能。开发者强调该软件适用于 AI 学习实验、电影制作和社会政治评论等伦理用途。
