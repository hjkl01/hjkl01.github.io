### [VulnClaw](https://github.com/Unclecheng-li/VulnClaw) ![GitHub Repo stars](https://img.shields.io/github/stars/Unclecheng-li/VulnClaw?style=social)

VulnClaw 是一款 AI 驱动的渗透测试 CLI 工具，支持自然语言输入，自动执行从信息收集、漏洞发现、漏洞利用到报告生成的全流程。其核心特性包括基于 LLM Agent 和 MCP 工具链的目标驱动求解引擎（替代传统固定轮数工作流）、证据级反幻觉机制以防止虚假结论，以及提供 21 个渗透 Skill 和 13 个 LLM 提供商支持。项目适用于已授权的渗透测试、CTF 竞赛及安全教学，具备 Web UI、TUI 工作台及持续性渗透测试等功能。
