### [ai-berkshire](https://github.com/xbtlin/ai-berkshire) ![GitHub Repo stars](https://img.shields.io/github/stars/xbtlin/ai-berkshire?style=social)

AI Berkshire 是一套兼容 Claude Code 与 Codex 的价值投资研究框架，旨在通过 AI Agent 实现专业级投研。其核心功能包括：

1. **四大师方法论融合**：系统化整合巴菲特、芒格、段永平、李录的投资逻辑，通过多视角对抗与结构化分析，强制输出明确的投资决策建议（通过/不通过/灰色地带）。
2. **高精度数据验证**：内置金融严谨性工具，使用精确计算库交叉验证财务数据，防止 AI 幻觉，确保估值与分析的准确性。
3. **18 个专业 Skills**：覆盖深度研究、财报精读、行业筛选、持仓管理及思维工具等全场景。支持多 Agent 并行研究，模拟真实投研团队协作。
4. **决策纪律与反偏见**：内置快速否决清单、逆向检验及留白原则，强制研究者面对不确定性，避免盲目乐观。
5. **实盘验证**：框架背后有经过实盘检验的投资体系，具备可复现的研究流程和清晰的决策依据。
