### [podman](https://github.com/podman-container-tools/podman) ![GitHub Repo stars](https://img.shields.io/github/stars/podman-container-tools/podman?style=social)

Podman是一款用于管理OCI容器、镜像、卷及Pod的工具。它支持多平台（Linux、Mac、Windows），具有无守护进程、兼容Docker CLI、安全资源隔离等特点，并基于libpod库实现生命周期管理。此外提供命令行接口与REST API，配合Skopeo、Buildah等子项目共同构成容器工具链生态。
