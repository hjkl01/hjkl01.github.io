### [Pumpkin](https://github.com/Pumpkin-MC/Pumpkin) ![GitHub Repo stars](https://img.shields.io/github/stars/Pumpkin-MC/Pumpkin?style=social)

Pumpkin 是一个完全使用 Rust 语言开发的 Minecraft 服务器软件，旨在提供快速、高效且可定制的游戏体验。其核心功能包括：

1. **高性能**：利用多线程技术实现最大速度和效率。
2. **高兼容性**：支持最新的 Java 版和基岩版 Minecraft 服务器版本，并严格遵循原版游戏机制。
3. **安全性**：优先防止已知的安全漏洞利用。
4. **灵活性与可扩展性**：高度可配置，允许禁用不必要的功能，并为插件开发提供基础支持。

主要特性涵盖协议支持（如加密、数据包压缩）、世界管理（加载、保存、光照、实体生成等）、玩家交互（移动、库存、战斗、经验等）、实体系统、服务器管理（命令、权限、聊天、RCON 等）以及代理支持（Bungeecord、Velocity）。目前该项目仍处于积极开发阶段。
