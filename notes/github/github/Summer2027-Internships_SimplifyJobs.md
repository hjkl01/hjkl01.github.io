### [Summer2027-Internships](https://github.com/SimplifyJobs/Summer2027-Internships) ![GitHub Repo stars](https://img.shields.io/github/stars/SimplifyJobs/Summer2027-Internships?style=social)

本项目是一个由匹兹堡大学计算机科学俱乐部（Pitt CSC）和 Simplify 共同维护的开源仓库，用于整理和分享 **2027年夏季技术类实习岗位** 信息。

主要功能包括：

- **按类别汇总实习岗位**：涵盖软件工程（103个）、产品管理（20个）、数据科学/AI与机器学习（86个）、量化金融（61个）、硬件工程（10个）等方向，共计约280个岗位。
- **实时更新**：由社区贡献者和 Simplify 每小时自动抓取各大科技公司及初创公司招聘页面，每日更新。
- **提供申请入口**：每个岗位附有其公司招聘页面链接，并支持通过 Simplify 一键自动填充申请。
- **辅助筛选标识**：使用图标标注是否提供签证担保、是否要求美国公民身份、申请是否已关闭、是否为 FAANG+ 公司、是否要求研究生学历等信息。
- **延伸资源链接**：提供已关闭岗位、非夏季实习、校招全职岗位及历史存档的关联链接。
- **社区驱动**：欢迎用户通过提交 Issue 贡献新岗位信息。
