### [CheatSheetSeries](https://github.com/OWASP/CheatSheetSeries) ![GitHub Repo stars](https://img.shields.io/github/stars/OWASP/CheatSheetSeries?style=social)

**OWASP 快速参考指南系列**是开源应用安全项目的官方文档库，专注于为开发者提供应用安全防护的最佳实践指南。项目提供结构化的快速参考文档，帮助开发者理解和实施安全开发规范。

**核心功能：**
- 提供 OWASP 官方快速参考指南，涵盖应用安全实践
- 支持本地构建和离线访问（ZIP包下载）
- 支持 Markdown 文档的语法和术语检查
- 提供 Docker/Podman 容器化构建和运行方案
- 设有 Slack 协作平台供团队交流
- 开放社区贡献机制，接受代码提交、问题反馈和改进建议
- 由多位项目领导者及核心团队成员维护
