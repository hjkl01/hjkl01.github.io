### [exercises-dataset](https://github.com/hasaneyldrm/exercises-dataset) ![GitHub Repo stars](https://img.shields.io/github/stars/hasaneyldrm/exercises-dataset?style=social)

该项目是一个包含1,324个健身动作的结构化多语言数据集及开发者设置向导。数据涵盖动作分类、目标肌群、所需设备及详细操作指南，支持英、西、意、土、俄、中六种语言。项目提供交互式浏览器用于数据浏览，以及开发工具辅助数据库构建、API集成和后端代码生成。注：原始多媒体文件（图片/GIF）未包含在内，仅保留媒体引用ID。
