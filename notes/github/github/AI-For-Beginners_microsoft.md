# Microsoft AI For Beginners 项目总结

**项目定位**：微软提供的初学者友好型人工智能课程，共12周24课时。

**核心功能**：
- 系统化AI教学内容，涵盖符号AI、神经网络、深度学习、计算机视觉、自然语言处理及AI伦理
- 提供可执行的Jupyter Notebook，支持PyTorch和TensorFlow两种框架
- 每课含预习材料、实操笔记和实验练习
- 配备测验应用（本地运行或Azure部署）

**教学特点**：
- 零基础入门，循序渐进
- 理论与实践结合
- 多语言支持（50+语种）
- 配套社区Discord交流

**额外资源**：
- 初学者友好示例（Hello AI World、神经网络基础等）
- 与Microsoft Learn模块联动
- 教师专用设置指南

**技术栈**：Python、PyTorch、TensorFlow、Jupyter Notebook
