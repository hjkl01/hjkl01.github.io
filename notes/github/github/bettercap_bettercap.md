### [bettercap](https://github.com/bettercap/bettercap) ![GitHub Repo stars](https://img.shields.io/github/stars/bettercap/bettercap?style=social)

bettercap 是一个用 Go 编写的强大、可扩展且便携的网络攻击与侦察框架，面向安全研究人员、红队人员和逆向工程师。

**核心功能：**
- **WiFi**：网络扫描、去认证攻击、PMKID 关联攻击、WPA/WPA2/WPA3 握手包捕获
- **BLE**：蓝牙低功耗设备扫描、特性枚举、读写
- **HID**：2.4GHz 无线设备扫描、MouseJacking 攻击（支持 DuckyScript）
- **CAN-bus**：帧解码、注入和模糊测试（支持 DBC）
- **网络侦察**：被动/主动 IP 主机探测、快速端口扫描
- **中间人攻击**：ARP、DNS、NDP、DHCPv6 欺骗器（支持 IPv4/IPv6）
- **代理**：数据包级、TCP 级、HTTP/HTTPS 级代理，支持 JavaScript 插件脚本化
- **嗅探与模糊测试**：凭证抓取、网络协议模糊测试
- **API 与 UI**：REST API（支持 WebSocket 异步事件）、Web UI
