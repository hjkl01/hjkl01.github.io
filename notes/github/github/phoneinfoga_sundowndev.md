### [phoneinfoga](https://github.com/sundowndev/phoneinfoga) ![GitHub Repo stars](https://img.shields.io/github/stars/sundowndev/phoneinfoga?style=social)

PhoneInfoga 是一款先进的国际电话号码信息收集与侦察框架。它主要用于扫描电话号码，获取国家、地区、运营商和线路类型等基础信息，并利用外部 API、电话簿和搜索引擎进行 OSINT 足迹调查，以识别 VoIP 提供商、查询声誉报告、社交账号及虚拟号码等信息。项目提供网页图形界面、REST API 及 Go 模块供调用。需明确的是，该工具仅用于信息搜集与调查辅助，不支持实时定位、追踪设备或破解手机。
