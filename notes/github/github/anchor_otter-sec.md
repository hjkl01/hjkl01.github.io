### [anchor](https://github.com/otter-sec/anchor) ![GitHub Repo stars](https://img.shields.io/github/stars/otter-sec/anchor?style=social)

Anchor 是 Solana 程序（智能合约）开发中最流行的框架。它提供了一系列便捷的开发者工具，主要包括：用于编写 Solana 程序的 Rust 领域特定语言（DSL）、IDL 规范、基于 IDL 生成客户端的 TypeScript 包，以及用于开发完整应用的 CLI 和工作区管理功能。其开发流程类似于以太坊生态中的 Solidity 和 Truffle，涵盖 RPC 请求处理程序编写、IDL 生成及客户端代码自动生成。此外，框架还集成了基于 Crucible 的模糊测试（Fuzzing）功能以辅助程序测试。
