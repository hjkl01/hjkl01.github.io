### [macro](https://github.com/macro-inc/macro) ![GitHub Repo stars](https://img.shields.io/github/stars/macro-inc/macro?style=social)

Macro 是一个集邮件、消息、文档、任务、代码、AI 代理、通话和 CRM 于一体的全能工作区。它通过共享的团队级记忆实现所有内容的双向链接与可查询性，确保用户和 AI 代理不丢失上下文。

核心功能包括：
*   **高效沟通**：提供极速的键盘优先邮件客户端、专注深度工作的团队频道聊天以及统一的收件箱（整合邮件、消息、任务等）。
*   **协作与记录**：支持版本控制、实时协同的 Markdown 文档，以及自动导入且全搜索的文件存储。
*   **任务与看板**：基于聊天的键盘优先任务管理，以及包含嵌入式链接的 2D 画布（Canvas）。
*   **AI 代理集成**：拥有统一记忆的团队级 AI 代理，能跨模块采取行动，并支持连接 Claude Code、Codex 等 MCP 客户端。
*   **销售管理**：内置 CRM，支持联系人对象、自定义属性及邮箱同步。
*   **安全与开源**：具备企业级安全标准（SOC 2 Type II 认证），完全开源（AGPLv3 许可），支持自托管。
