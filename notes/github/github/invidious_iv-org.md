### [invidious](https://github.com/iv-org/invidious) ![GitHub Repo stars](https://img.shields.io/github/stars/iv-org/invidious?style=social)

Invidious 是一个开源的 YouTube 替代前端，主要功能包括：

**核心特点**
- 轻量级、无广告、无追踪、无需 JavaScript
- 支持亮色/暗色主题和可定制首页
- 多语言支持

**用户功能**
- 独立于 Google 的订阅管理
- 订阅频道通知
- 音频播放模式（移动端支持后台播放）
- Reddit 评论支持

**数据支持**
- 支持从 YouTube、NewPipe、FreeTube 导入订阅和观看历史
- 支持导出订阅到 NewPipe 和 FreeTube
- 导入/导出 Invidious 用户数据

**技术特性**
- 支持视频嵌入
- 提供开发者 API
- 不依赖官方 YouTube API
- 无需签署贡献者许可协议（CLA）

**使用方式**
- 可直接使用公共实例观看视频
- 支持自建部署
