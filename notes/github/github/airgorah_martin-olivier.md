### [airgorah](https://github.com/martin-olivier/airgorah) ![GitHub Repo stars](https://img.shields.io/github/stars/martin-olivier/airgorah?style=social)

Airgorah 是一款基于 Rust 和 GTK4 开发的 WiFi 安全审计工具。主要功能包括捕获附近 WiFi 流量、发现已连接客户端、执行去认证攻击、抓取握手包以及破解无线密码。该软件基于 aircrack-ng 套件，仅支持 Linux 系统，运行需 root 权限及支持监听模式与数据包注入的无线网卡，专为网络所有者进行合法安全测试与漏洞排查设计。
