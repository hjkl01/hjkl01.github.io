### [cs249r_book](https://github.com/harvard-edge/cs249r_book) ![GitHub Repo stars](https://img.shields.io/github/stars/harvard-edge/cs249r_book?style=social)

本项目是一套开源的“AI工程”（机器学习系统）综合课程与教材体系，旨在填补AI模型研发与生产级系统部署之间的工程鸿沟。核心功能模块如下：

- **双卷教材**：系统讲授从单机优化到大规模分布式部署的ML系统理论、量化推理与设计原则，涵盖数据流、训练扩展、推理服务、容错治理等全链路知识。
- **TinyTorch**：提供20个渐进式编程模块，引导学习者从零实现核心计算图、自动求导、优化器与分布式通信，深入掌握ML框架底层机制。
- **交互式实验（Labs）**：基于Marimo笔记本的动态实验环境，支持实时调整参数并观察系统行为，结合内置仿真引擎培养架构权衡直觉。
- **硬件部署套件（Kits）**：指导将模型实际部署至Arduino、树莓派、Grove等边缘设备，直面真实的内存限制、功耗预算与延迟约束。
- **MLSys·im 基础设施模拟器**：用于建模与计算在物理环境中难以获取的大规模数据中心场景下的内存瓶颈、网络带宽饱和及调度策略。
- **StaffML 面试题库**：提供基于系统物理规律与工程约束的ML岗位面试题、模拟面试与进度追踪工具，强化实战设计能力。
- **教育者支持中心**：包含标准化教学大纲、多主题课件、评估量规、TA手册及课程更新通讯，便于高校与培训机构快速落地课程。

整体学习路径为“阅读→探索→构建→建模→部署→实践→教学”，面向学生、转岗工程师与教育工作者，致力于培养能够独立设计、优化并交付高效、可靠、安全端到端智能系统的AI工程师。
