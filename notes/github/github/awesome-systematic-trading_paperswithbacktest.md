### [awesome-systematic-trading](https://github.com/paperswithbacktest/awesome-systematic-trading) ![GitHub Repo stars](https://img.shields.io/github/stars/paperswithbacktest/awesome-systematic-trading?style=social)

这是一个系统化交易（量化交易）的资源库，收集和整理了以下核心内容：

1. **97个开源库和包**：涵盖回测、实盘交易框架、技术指标分析、组合优化、定价模型、风险管理等
2. **40+种量化策略**：按债券、商品、货币、股票等不同资产类别分类，包含学术机构提出的经典策略
3. **55本推荐书籍**：分为初学者、传记、编码、加密货币、通用、高频交易、机器学习等多个领域
4. **23个视频和访谈**：提供关于机器学习和量化交易的教程与专家观点
5. **精选博客和课程**：包含学习资源和专业资讯渠道
