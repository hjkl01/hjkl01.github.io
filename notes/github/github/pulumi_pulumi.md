### [pulumi](https://github.com/pulumi/pulumi) ![GitHub Repo stars](https://img.shields.io/github/stars/pulumi/pulumi?style=social)

Pulumi 是一款面向人类和智能体的现代基础设施即代码（IaC）工具。它允许开发者使用熟悉的编程语言（如 TypeScript、Python、Go、Java 等）而非 YAML 来构建和部署云基础设施。支持 AWS、Azure、GCP、Kubernetes 及 300 多种提供商，提供自动化资源配置、状态管理、日志查看及安全密钥管理功能，旨在简化跨多云环境的开发体验。
