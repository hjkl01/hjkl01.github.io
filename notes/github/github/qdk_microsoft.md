### [qdk](https://github.com/microsoft/qdk) ![GitHub Repo stars](https://img.shields.io/github/stars/microsoft/qdk?style=social)

Microsoft Quantum Development Kit 是用于 Q# 语言的量子开发工具包，提供完整的开发体验。其核心功能包括：

1. **编译器与运行时**：包含 Q# 核心编译器逻辑及命令行工具。
2. **集成开发环境支持**：提供 Visual Studio Code 扩展和 JupyterLab 扩展，支持代码编辑、语言服务及小部件展示。
3. **在线交互平台**：包含用于手动验证更改的本地游乐场（Playground）网站，以及基于 WebAssembly 的模块绑定。
4. **标准库与资源估算**：提供 Q# 标准库实现及 Microsoft 量子资源估算器（Quantum Resource Estimator）。
5. **包管理分发**：通过 npm 和 pip 分别发布 Q# 的 JavaScript 和 Python 包。
6. **测试与示例**：包含模糊测试基础设施、教程（Katas）和示例代码（Samples）。

该工具包 powering 了 quantum.microsoft.com 上的 Q# 开发体验。
