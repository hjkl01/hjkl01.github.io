### [project-based-learning](https://github.com/practical-tutorials/project-based-learning) ![GitHub Repo stars](https://img.shields.io/github/stars/practical-tutorials/project-based-learning?style=social)

这是一个面向软件开发初学者的项目式学习教程集合。该仓库整理了按编程语言分类的实战项目教程，帮助学习者通过从零构建应用程序来掌握编程技能。覆盖的语言包括 C/C++、C#、Python、JavaScript、Go、Rust、Swift 等主流语言，内容涉及 Web 应用开发、游戏开发、系统编程、网络编程、机器学习、深度学习、编译器开发、操作系统实现等多个方向，并附有额外的学习资源链接。
