### [msgspec](https://github.com/msgspec/msgspec) ![GitHub Repo stars](https://img.shields.io/github/stars/msgspec/msgspec?style=social)

msgspec 是一个高性能的 Python 序列化与验证库，支持 JSON、MessagePack、YAML 和 TOML。其核心功能包括：提供业界领先的快速编解码器；利用 Python 类型注释实现零成本的架构校验；以及提供比 dataclasses 和 attrs 快 5-60 倍的 Struct 数据类型。该库为轻量级设计且无依赖推荐用于完整的序列化与校验工作流。
