# best-resume-ever 项目功能总结

这是一个基于 Vue 和 LESS 构建的简历生成工具，可快速创建多种风格的精美简历。

**主要功能：**
- 提供多种简历模板：Cool、Creative、Green、Purple、Side Bar、Left Right、Material Dark、Oblique 等
- 支持 RTL（从右到左）语言布局
- 用户可编辑 `resume/data.yml` 自定义简历内容
- 支持导入个人头像照片
- 提供本地预览功能（npm run dev）
- 支持一键导出为 PDF（npm run export）

**技术栈：** Vue、LESS、Puppeteer  
**环境要求：** Node.js 8.5.0 或更高版本
