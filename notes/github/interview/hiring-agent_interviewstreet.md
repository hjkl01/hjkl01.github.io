### [hiring-agent](https://github.com/interviewstreet/hiring-agent) ![GitHub Repo stars](https://img.shields.io/github/stars/interviewstreet/hiring-agent?style=social)

该项目是一个简历评分代理（Hiring Agent），提供从简历到评分的端到端流水线。主要功能包括：解析 PDF 简历并提取结构化数据，利用 GitHub 信号进行信息增强，最后基于公平性约束生成客观、可解释的评估报告（包含分类分数、证据及加减分项）。支持本地部署（Ollama）或云端服务（Google Gemini），并提供命令行接口及 CSV 导出功能。
