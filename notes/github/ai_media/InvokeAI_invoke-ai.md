# InvokeAI 项目功能总结

InvokeAI 是一款面向专业用户和爱好者的开源创意AI工具，用于生成和创作视觉媒体内容，采用商业友好许可证免费使用。

**核心功能：**

- **Web UI**：基于 React 的本地托管网页界面，提供优质的用户体验
- **统一画布**：支持图像生成、内补/外补绘、画笔工具等，可作为AI创意协作工具，增强AI生成图像、草图、摄影和渲染图
- **工作流与节点系统**：基于节点的自定义生成管道，支持开发、管理和分享定制化工作流
- **画板与画廊管理**：图片的存储、检索、二次创作，支持拖放操作和富元数据记录
- **多模型支持**：涵盖 SD 1.5/2.0/SDXL/SD 3.5、Flux 全系列、CogView 4、Z-Image、Krea、Anima、Qwen、Ideogram、ERNIE 等数十种模型
- **附加功能**：超分辨率工具、嵌入与模型管理器、对象分割与选择模型（SAM/SAM2）、支持 ckpt/diffusers/gguf 等多种模型格式

项目由全球贡献者共同维护，支持通过 Discord 和社区获取帮助。
