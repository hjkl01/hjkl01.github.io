### [ComfyUI](https://github.com/Comfy-Org/ComfyUI) ![GitHub Repo stars](https://img.shields.io/github/stars/Comfy-Org/ComfyUI?style=social)

**ComfyUI 功能总结**

ComfyUI 是一款面向视觉专业人员的强大且模块化的 AI 内容创作引擎。

核心功能：
- 可视化节点图界面，无需编码即可构建图像、视频、音频、3D 和文本工作流
- 支持开源模型（Stable Diffusion、Flux、Wan、CogVideoX 等）和闭源 API 模型
- 提供 App Mode 简化复杂工作流，内置 API 支持生产管线集成
- 高效本地执行：异步队列、部分重执行、智能显存/内存管理、模型卸载、量化支持
- 内置修复、扩展、遮罩合成、模型合并、超分辨率、帧插值等工具
- 支持工作流 JSON 保存/加载，可从生成图片恢复完整工作流和种子
- 支持自定义节点扩展
- 完全离线运行，支持 Windows、Linux、macOS，本地桌面应用及云端部署
- 支持 NVIDIA、AMD、Intel、Apple Silicon、Ascend NPU 等多种硬件
