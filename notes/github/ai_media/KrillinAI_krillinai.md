### [KrillinAI](https://github.com/krillinai/KrillinAI) ![GitHub Repo stars](https://img.shields.io/github/stars/krillinai/KrillinAI?style=social)

KrillinAI 是一款面向人类用户和 AI Agent 的视频本地化与增强工具。它提供从视频下载、语音识别、字幕翻译、TTS 配音到画面适配的一站式解决方案，支持横屏与竖屏格式，完美适配 Bilibili、YouTube、TikTok 等主流平台。项目具备 CLI 接口、自动化流水线编排及 Agent 技能集成能力，兼容多种开源及商业大模型与语音服务，并支持 Windows、Linux 和 macOS 多平台部署。
