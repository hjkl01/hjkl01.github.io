### [opensre](https://github.com/Tracer-Cloud/opensre) ![GitHub Repo stars](https://img.shields.io/github/stars/Tracer-Cloud/opensre?style=social)

OpenSRE是一个开源的AI SRE（站点可靠性工程）框架，用于构建和管理AI驱动的基础设施故障处理代理。其核心功能包括：自动收集和分析日志、指标、追踪及部署上下文信息；通过连接60+工具和自定义工作流进行根因分析；生成结构化报告并提出修复建议；支持Slack、Telegram等平台的实时协作与告警；提供本地交互式会话或远程服务深度调查能力，并可在用户自有基础设施上部署运行。
