### [fleet](https://github.com/fleetdm/fleet) ![GitHub Repo stars](https://img.shields.io/github/stars/fleetdm/fleet?style=social)

Fleet 是一款面向拥有大量计算机设备的 IT 和安全团队的开源管理平台。它提供统一的系统，支持通过空中接口对计算设备进行安全管理与维护，涵盖移动设备管理（MDM）、补丁更新、软件部署及合规性验证等功能。该平台兼容 Linux、macOS、Windows、Chromebook、iOS、Android 以及多种云服务和容器环境，具备轻量级、模块化设计，支持与 GitOps、REST API 及各类企业工具集成，并严格保护用户隐私。
