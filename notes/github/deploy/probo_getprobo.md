### [probo](https://github.com/getprobo/probo) ![GitHub Repo stars](https://img.shields.io/github/stars/getprobo/probo?style=social)

**Probo 是一款开源的 GRC（治理、风险、合规）平台**，专为工程和安全团队设计，支持自托管部署。

**核心功能：**
- **风险管理**：风险登记册、固有风险/剩余风险评估、威胁驱动的风险评估
- **控制与框架**：控制库、自定义框架导入导出、适用性声明（SoA）
- **供应商风险**：供应商清单、自动网站风险评估、DPA/BAA 跟踪
- **数据隐私**：DPIA、传输影响评估、数据处理记录、数据清单、访问权请求处理
- **访问审查**：审查活动管理、权限决策、与 SaaS/云基础设施/源码集成
- **审计程序**：审计范围界定、控制映射、发现项跟踪、报告生成
- **文档管理**：版本控制文档、审批机制、电子签名、PDF 导出
- **合规门户**：公共合规页面、NDA 管理、认证发布

**技术特点：**
- AI 原生架构，提供 270+ MCP 工具，支持 LLM 代理自动处理 GRC 数据
- 多接口支持：Web 控制台、`prb` CLI（44+ 命令组）、MCP API、GraphQL API、n8n 工作流集成
- MIT 开源许可，基于 Go + PostgreSQL 构建
- 审计就绪：基于策略的 RBAC、不可变审计日志、电子签名工作流、证据链管理
