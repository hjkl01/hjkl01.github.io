### [semaphore](https://github.com/semaphoreui/semaphore) ![GitHub Repo stars](https://img.shields.io/github/stars/semaphoreui/semaphore?style=social)

Semaphore UI 是一款现代化的 Web 界面，用于管理 DevOps 工具链。

**核心功能：**
* 支持执行 Ansible Playbook、Terraform/OpenTofu/Terragrunt 代码以及 Bash 和 PowerShell 脚本
* 提供任务执行通知（失败告警）
* 支持访问控制和权限管理
* 支持定时任务调度
* 内置资源管理：项目、任务模板、库存（目标主机）、变量组（敏感信息存储）

适用于项目规模增长后，不再适合直接通过终端进行部署管理的场景。
