### [OpenList](https://github.com/OpenListTeam/OpenList) ![GitHub Repo stars](https://img.shields.io/github/stars/OpenListTeam/OpenList?style=social)

OpenList 是一个基于 AList 的开源云盘列表程序，主要功能包括：

- **多存储支持**：支持本地存储、阿里云盘、OneDrive/SharePoint、189云、Google Drive、FTP/SFTP、S3、WebDAV 等40余种存储服务
- **文件预览**：支持 PDF、Markdown、代码、纯文本、Office 文档（docx/pptx/xlsx）及 README.md 预览渲染
- **多媒体播放**：图片画廊模式预览，音视频播放支持歌词和字幕
- **文件管理**：支持 Web 上传（可开放访客）、删除、创建目录、重命名、移动、复制及打包下载
- **离线下载**：支持添加任务离线下载
- **跨存储操作**：支持在不同存储间复制文件
- **WebDAV 服务**：可作为 WebDAV 服务端使用
- **安全防护**：支持受保护路由（密码保护和认证）
- **界面特性**：暗色模式、多语言国际化（I18n）
- **下载加速**：单线程下载/流媒体支持多线程加速
- **便捷部署**：支持 Docker 部署、Cloudflare Workers 代理，开箱即用
