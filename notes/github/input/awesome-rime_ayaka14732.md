# 项目功能总结

**awesome-rime** 是一个 RIME（中州韵）输入法输入方案和配置的精选资源列表，收录了各类中文及多语言输入方案，涵盖以下类别：

- **形码与音形**：五笔字型、仓颉、郑码、双拼、自然码、小鹤音形等主流及特色形码输入方案
- **音码**：明月拼音、双拼、注音、宫保拼音、带声调拼音等多种拼音方案
- **汉语方言**：上古汉语、中古汉语、各地方言（吴语、粤语、闽南语、客家话、晋语等）输入方案
- **非汉语/非汉字**：日语、韩语、越南语、拉丁字母、IPA音标、藏文、满文、蒙古文、世界语、克林贡语等特殊文字输入方案
- **配置**：雾凇拼音、白霜拼音等流行配置方案
- **其他**：Emoji、LaTeX 符号、颜文字等特殊输入方案

该项目为 RIME 用户提供了全面的输入方案选择，支持从主流中文输入法到各类方言、少数民族文字乃至人造语言的多样化输入需求。
